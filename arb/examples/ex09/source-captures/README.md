# Source captures

This directory contains sanitized publication copies of the source captures used in the case packet.

Raw HTML was not copied. HTML captures were converted to text and stripped of scripts, styles, SVG, comments, repeated navigation, unrelated page chrome, and obvious support/contact email boilerplate. The Polymarket Gamma API capture was reduced to market, event, rule, outcome, dispute-status, and provenance fields. The market image is copied unchanged.
