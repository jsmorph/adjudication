# Source captures

This directory preserves structured Polymarket API captures for the May 24 Iran airspace market.

The raw Polymarket HTML pages captured during case preparation are intentionally not included in this staging tree. Those pages contained unrelated trader comments, public profile links, page chrome, and analytics markup. The rule text, market identifiers, dates, outcome state, and capture notes needed for this repository are preserved in `../case-packet/market-page.txt` and the structured Gamma JSON files here.

Included files:

- `polymarket-gamma-event.json`
- `polymarket-gamma-market-may-24.json`
